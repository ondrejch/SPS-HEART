# 10-scan_nstar_smoothness

Run the N* smoothness-prior scan starting from the balanced constrained fit.

Run:

```bash
./10-scan_nstar_smoothness/run.sh
```

Default lambdas:

- `0,0.1,0.3,1,3,10,30,100,300,1000`

Outputs:

- `00runs/nstar_smooth_prior_scan_<stamp>`
- `nstar_smooth_prior_scan_metrics.png`
